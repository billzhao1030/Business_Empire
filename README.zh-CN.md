# 💼 Business Empire · 商业帝国

一个可以在浏览器里玩的商业模拟经营游戏。**从 $0 开始**：先打零工攒第一笔钱，开出第一个街头小摊，
然后一路做到炒股、买房、投资商圈，最后把一家家上市公司整个收购下来，冲上世界富豪榜。

**零第三方依赖** —— 只需要 Node.js，不用 `npm install`，不联网也能玩，没有广告。
存档保存在本地 SQLite 数据库里，支持多账号，各自独立。界面支持**中文 / English**、**三套配色主题**。

## 🚀 快速开始

### macOS

桌面上已经有一个 **Business Empire** 图标，双击即可：

- 服务**没启动** → 后台自动拉起（约 0.7 秒），起来后自动打开浏览器
- 服务**已经在跑** → 直接打开浏览器（约 0.07 秒）
- 关掉浏览器不会停止服务；服务独立于启动器存活

启动器做了这些健壮性处理：严格校验 `/api/health` 返回 `{"ok":true}` 才算启动成功、
全部使用系统命令绝对路径（Finder 启动的 App 环境变量极简）、多路径搜索项目目录、
通过登录 shell 兜底查找 `node`、启动前先探测存档目录写权限、
日志写到 `~/Library/Logs/BusinessEmpire.log`（避开 TCC 保护目录）、App 已做 ad-hoc 签名。

移动过项目文件夹后，重新生成图标：

```bash
cd "Business Empire" && ./tools/make-desktop-icon.sh
```

也可以手动启动：`node server.js`，然后访问 <http://127.0.0.1:8020>。

### Windows

1. **安装 Node.js**（只需一次）。在 PowerShell 里执行：

   ```powershell
   winget install OpenJS.NodeJS.LTS
   ```

   或去 <https://nodejs.org> 下载 **LTS** 安装包。装完**关闭并重新打开**终端。

2. **确认版本**（需要 v22.5 以上，推荐 v24 及以上）：`node -v`

3. **启动游戏**，二选一：
   - 双击 **`start.bat`**（会保留一个命令行窗口，关掉即停止服务）
   - 双击 **`Business Empire.vbs`**（无窗口后台启动，更像一个 App）
     → 右键它 → **发送到 → 桌面快捷方式**，就得到一个桌面图标，逻辑和 macOS 版一样：
     没启就启，启了就直接开网页

4. 停止服务：关掉命令行窗口，或在任务管理器里结束 `node.exe`。

> Node 是 v22 / v23 的话，改用 `node --experimental-sqlite server.js`（或 `npm run start:legacy`）。

### Linux

```bash
node -v && node server.js     # 然后打开 http://localhost:8020
```

## 🎮 玩法说明

### ⏱️ 时间

**现实 1 分钟 = 游戏 1 小时**。一个游戏日 = 24 分钟，一个游戏月（30 天）= 12 小时现实时间，
一个游戏年 = 6 天。

**离线也会照常结算**：关掉网页去睡觉，回来时店铺的营业额、银行利息、贷款月供、
股价波动、房价涨跌全部一次性补算。
**但离线收益最多只结算 7 个游戏日**——生意不会替你无限囤积（行情本身仍会推进完整时长）。

再次打开游戏时会弹出一份「**欢迎回来**」报告，告诉你：离开了多久（现实时间与游戏时间）、
净资产变化了多少、这些钱**分别是从哪儿来的**（实业 / 打工 / 股息 / 租金 / 利息）、
花到哪儿去了（税 / 还贷 / 维护费），以及有多少来自资产估值波动。

### 🧳 白手起家（开局这么玩）

你的初始资金是 **$0**。

1. 开局身上 **$0**。上班时段（09:00–17:00）工资自动结算；非上班时段到**生涯**页接加班：
   每单实打实占用 **1 个游戏工时**（现实 1 分钟），干完才到账，期间不能再接第二单
2. 深夜（23:00–07:00）也能加班，有 **2.2× 夜班津贴**，但体力消耗极大——熬夜是有代价的
3. 攒到 **$50** 开出第一个街头小摊，它会替你 24 小时不停地赚钱
4. 攒到 **$900** 买一辆二手电动车 → 解锁「网约车司机」，时薪从 $8 涨到 $28
4. 用店铺利润滚出更多店铺，同时开始炒股、买商圈份额
5. 信用分够了就贷款加杠杆，买房吃租金
6. 终局：买满一家公司的限购比例，发起**全面收购要约**，把它变成全资子公司

**一天被切成三段，工时和身体双重封顶：**

| 时段 | 内容 |
| --- | --- |
| 23:00 – 07:00 | 睡觉恢复体力；也可以熬夜加班，2.2× 津贴但 -20 体力 |
| 09:00 – 17:00 | 正常班 8 小时，自动结算工资 |
| 07:00–09:00 / 17:00–23:00 | 加班时段，1.6× 加班费，-9 体力 |

加班每天最多 6 小时。

**加班是真的要花时间的**：接一单 = 占用 **1 个游戏工时**（现实 1 分钟），
这一小时在游戏里真正过完钱才到账，期间**不能再接第二单**——不可能一分钟里连接两次。

加班还会消耗**体力**（0–100）。体力低于 60 工作效率开始下降，低于 15 就干不动加班了。
每天加 **4 小时以内可持续**，加满 6 小时会把自己熬垮，得停一两天补觉。

12 个职位（时薪 $8 → $900，按现实标准定标）：发传单 → 送外卖 → 便利店店员 → 餐厅服务员 →
**网约车司机**（需有车）→ **长途货车司机**（需有车）→ 销售代表 → 软件工程师 →
金融分析师 → 部门经理 → 投行副总裁 → 职业经理人 CEO。每工作 1 个工时 +1 点经验。

游戏内时间常驻在**界面顶部**，显示日期、时钟、当前小时进度和你所处的时段
（🌙 休息 / 🌅 清晨 / 💼 上班中 / 🌆 已下班）。

### 🕯️ 市场传闻：会应验的隐晦信号

行情页上有一栏**市场传闻**。它们从来不说「哪个板块要涨」，只说上下游看得见的细节：

> 港口的滚装船位排到了三个月之后　　　　　`汽车`
> 经销商的库存周转天数，悄悄从 18 天拉长到 41 天　　　`汽车`
> 封测厂开始三班倒，工程师的加班表排到了下个季度　　　`半导体`
> 同业拆借利率连着五天走低，没人解释为什么　　　`银行`

板块会标出来，**方向要你自己从字面里读**。

这些不是气氛组。每条传闻背后都有一个**已经排好期的催化剂**：那个板块会在
30~110 个游戏小时之后真的动起来，幅度 5%~18%，持续两天多，内在价值同步重估——
涨上去是站得住的，不会被均值回归拉回来。

但也不是白送钱：

| 结果 | 概率 |
| --- | --- |
| 应验，朝你读出的方向走 | **70%** |
| 不了了之 | 18% |
| 反向走（放出来骗人的） | 12% |

用 28 个游戏月、113 轮传闻实测：

| 持有 | 平均收益 | 胜率 |
| --- | --- | --- |
| 3 游戏日 | +2.4% | 62% |
| 1 游戏周 | **+4.3%** | **67%** |
| 12 游戏日 | +5.1% | 68% |
| *对照：随机板块随机方向* | *−0.3%* | *—* |

看得懂就是真的有优势，但会被骗，也会踩空。点一条传闻就能直接筛出那个板块的股票。

### 🌏 开店：全世界 7,330 座城市任选

原来只有六个抽象档位，现在**地图上每一座城市都能开店**。当地经营参数是推出来的：
**物价** = 所在国家的世界银行收入分组 × 城市规模溢价；**客流** = 人口 + 世界城市/首都溢价。
家乡永远是 1.00 的基准。

**房租涨得比营收快**，这是大城市开店最难受的地方（以阿德莱德为基准，开一家夜市大排档）：

| 城市 | 营收 | 房租 | 建店成本 | 日净利 | 回本 |
| --- | --- | --- | --- | --- | --- |
| 🇦🇺 阿德莱德（家乡） | 1.00× | 1.00× | $16.0K | $261 | 61 天 |
| 🇯🇵 东京 | 2.06× | **3.62×** | $43.7K | $511 | **86 天** |
| 🇺🇸 纽约 | 1.82× | 2.89× | $36.7K | $425 | 86 天 |
| 🇹🇭 曼谷 | 1.14× | 1.16× | $17.4K | $330 | 53 天 |
| 🇮🇳 孟买 | 0.92× | 0.75× | $12.1K | $241 | 50 天 |
| 🇦🇺 霍巴特（小城） | 0.60× | 0.41× | $7.9K | $125 | 64 天 |

**大城市是用更差的回报率换更高的绝对利润**——正是现实里连锁扩张的取舍。回本最快的是
摩洛哥、肯尼亚、哈萨克斯坦这类中等物价的地方（约 39 天），但单店利润只有大城市的三分之一。
设备与装修按国际价走（成本有下限），再穷的地方也不可能几乎白开一家店。

去外地开店要**亲自跑一趟**：机票按真实大圆距离算 + 在外几天的食宿，这几天不能上班。

### 🏢 创业：从一家店到一家公司

一家店就是一家店，一家公司不一样——公司有**估值**。估值不是你投进去多少钱，
而是**年利润的倍数**：

| 倍数的构成 | 取值 |
| --- | --- |
| 基础 | 6.0× |
| 增长率 | 每 +100% 年增长 **+8×**（最要紧的一条） |
| 赛道热度 | 跟着股市板块轮动，±1.75× |
| 规模 | 店铺数每多一个数量级 +1.6× |
| **合计** | **2.5× ~ 45×** |

估值取三种算法里最高的一个：**按利润**（年利润 × 倍数）、**按营收**（只留给还没盈利
但年增长超过 50% 的公司）、**按清算**（店铺残值 + 公司现金，兜底）。用的是**滚动平滑**
的利润，不是此刻的瞬时值——否则小生意的客流波动会让市值一天砍半。

公司赚的钱进**公司账户**，不直接进你口袋：

- 拿去**开更多店** → 利润涨、增长涨、倍数涨 → 估值复利往上走
- **分红**到自己手上 → 缴 20% 的税 → 这才是你能花的钱

**融资**：估值和店铺数够格就能开谈。

| 轮次 | 估值门槛 | 店铺门槛 | 出让 | 投资人给的估值 |
| --- | --- | --- | --- | --- |
| 天使轮 | — | 1 家 | 15% | 你估值的 68% |
| A 轮 | $150K | 3 家 | 18% | 78% |
| B 轮 | $2M | 8 家 | 15% | 84% |
| C 轮 | $20M | 18 家 | 12% | 90% |

**公司不止能开一家**——最多同时经营 8 家，每家装不同的生意。估值、增长、融资进度、公司账户
全部各算各的：一家分红不会动另一家的钱，一家上市也不影响另一家。开新店时可以指定由谁出钱，
用哪家公司的钱开的店就归哪家。

投资人给的估值总比你自己算的低，增长越快、信用越好压得越少。每融一轮持股少一截——
这是拿别人的钱把生意做大必须付的价钱。未上市股权计入身家时打**七折**，卖不掉的钱不算钱。

### 🔔 上市：公司变成第 245 支股票

| 上市门槛 | |
| --- | --- |
| 融资轮次 | 至少走完天使 + A 轮 |
| 估值 | $5,000,000 |
| 名下店铺 | 12 家 |
| 盈利 | 必须已经盈利 |

公开发行 **25%** 的新股，发行价按估值定：大盘火热时承销商敢溢价发行，冷清时就得让利。
承销费 5%，其余进公司账户。

敲钟之后，**你的公司出现在行情页上，和 Appel、Envidia 排在一起**：

- 股价按自己的**经营基本面**做均值回归（内在价值 = 估值 ÷ 总股本），公司越赚钱股价越有底
- 你的股份变成一条**普通持仓**——可以卖掉换现金，也可以在市场上一点点买回来
- 身家和富豪榜名次从此跟着股价波动

一次完整的成长曲线：3 家店 $1.21M → 天使轮 → 8 家 $4.96M → A 轮 → 18 家 $16.37M →
**上市，发行价 $11.46，募资 $5.44M，市值 $21.9M**，创始人持股 69.7% → 52.3%。

### ⏱️ 游戏速度

顶栏右侧五档调速，从最慢 **5 分钟 = 1 游戏小时** 到最快 **12 秒 = 1 游戏小时**（相差 25 倍）。
调整时时钟以当前时刻为锚点重新对齐，不跳变、不影响存档。

### 🧠 压力、健康与旅游

借钱不只有利息成本。**负债率**超过 35%、**月供**吃掉三成以上收入，都会持续推高**精神压力**，
而且这些是**累加**的；加班加剧，熬夜更甚。

**连轴转同样要命**：连续工作超过 3 天，睡眠的恢复效率开始下降——第 7 天只剩 70%，第 14 天只剩 42%，
而且连轴本身每天还会额外累积十几点压力。睡一觉不可能把体力、压力和健康全补回来，
真正缓过来得**请假**（重置连续工作天数）或者**出去旅游**。

| 压力 | 后果 |
| --- | --- |
| > 50 | 工作效率开始下降，最低降到 70% |
| > 55 | 每小时都有生病的可能 |
| > 78 | 干不动加班了 |

**五种病**：重感冒 → 急性胃炎 → 焦虑性失眠 → 过劳衰竭 → 心脏警报。压力越高，病得越重。
生病期间无法上班，生意也因老板不在打九折。可以**去医院**花钱把卧床时间砍掉一半以上，
也可以硬扛——但硬扛时压力还在涨。

**旅游**是清空压力最有效的方式：$600 的周末短途 → $600 万的亚轨道太空飞行，共 7 条线路，
可选经济舱 / 商务舱 / 头等舱（**有私人飞机则免机票**）。
**旅途中完全无法工作**——正常班和加班都停，但你的生意照常运转。

### 💰 成本是按真实生意拆开的

| 项目 | 占比 / 规则 |
| --- | --- |
| 进货成本 | 营收的 **42%**，只在营业时发生 |
| 人工 | 约 **22%**——一名员工大约创造自身工资 4.5 倍的营收，人数按营收自动推算 |
| 房租 | 按开办成本比例逐月扣，**关门也照付**（擦鞋摊 $85/月，奶茶店 $3,294/月） |
| 净利率 | 稳定在 **26–30%** |
| 回本周期 | 小摊 **38 个游戏日** → 重资产 **330 天** |

**大城市营收更高，但房租涨得比营收更快**：同一家奶茶店，小镇 82 天回本，一线 148 天，迪拜 213 天。
去大城市图的是单店能吃下更多资本，而不是更高的回报率。

**异地开店必须亲自飞过去**：往返机票（省会 $450 → 迪拜 $9,800）+ 在当地待 1–3 天，这期间不能上班。

**当了老板就没法打工**：每家店每天占用你 0.8–4.7 小时的管理精力，超过 8 小时就得辞职专心当老板。
雇**店长**（月薪约为普通员工的 2 倍）可以把这块时间买回来。

### 🏬 实业（36 种业态，9 个可调杠杆）

从 **$50 的街头小摊**到 **$50 亿的商业航天基地**。每家店可以调：

- **选址**：小镇 / 本市 / 省会 / 一线城市 / 纽约 / 迪拜。城市越大投入越高、单位回报越好、波动也越大
- **定价策略（5 档）**：最有深度的一个机制。低价拉客流并**长期抬高**客流基准；
  高价短期利润高但顾客会**慢慢流失**。想快速回血就"收割"，想做大就压价抢份额
- **员工**：每名员工支撑一定营收，人手不足会直接丢订单并赶走客人。可开**自动配人**
- **扩建**（最高 Lv.12）：营收 ×1.32/级，成本 ×1.18/级
- **营销**（最高 6 级）：提营收 + 抬高客流基准
- **翻新**：店铺状况随时间衰减，状况差会同时压低营收、抬高成本。可开**自动翻新**
- **营业时间**：煎饼摊只做 6:00–11:00 的早餐，夜市大排档 18:00 才开门，便利店 24 小时。
  **只有营业时段才有营收和人工支出**，而房租 24 小时都在烧。可以花钱改成 24 小时营业

另外，店铺所在城市的**商圈繁荣度**会直接乘在营收上。

### 📈 市场（143 个可交易标的）

| 股票 | **200** | 谐音真实公司（Appel / MicroHard / Envidia / Teslo / 腾讯达 / 阿里爸爸 / 贝莱德客 / 茅苔 / 优步尔…），横跨 54 个板块，各有市盈率、股息率、β、总股本 |
| 商圈 | 12 | 可投资的商业地产份额，按季分红，繁荣度直接影响你在该城市所有店铺的营收 |

**新建存档时会先预热 30 个游戏日**，所以一进游戏每个标的就已经有一整月的历史行情和新闻，
不是从一个孤零零的点开始画线。

**价格是怎么来的**——不是随机数，也没有固定涨跌上下限。每个游戏小时，每个标的的
对数收益率由六部分叠加：

1. **大盘因子** × 该标的的 β
2. **板块因子与轮动**（每个板块有缓慢演化的动量，所以会出现半导体连涨一周这种行情）
3. **个股特异波动**（由它自己的年化波动率决定）
4. **均值回归**（每个标的有缓慢增长的**内在价值**，价格偏离越远被拉回来的力越大）
5. **波动率聚集**（GARCH 效应：大波动之后更容易继续大波动，行情有平静期和疯狂期）
6. **跳跃与新闻冲击**（突发跳空 + 会推动内在价值本身的新闻事件）

此外**你自己的大额交易会冲击价格**——买得越多，成交价被你推得越高。

游戏内的**行情 → 概览**页有大盘指数走势、涨跌家数分布、板块表现排行、涨跌幅榜和实时新闻流；
每个标的的详情页有折线 / K 线切换、4 档时间区间、MA5/MA20 均线、区间高低、波动率、β、内在价值。

### 🌍 宏观经济周期

世界不是静止的。每个游戏月重掷一次宏观周期：
**繁荣 → 扩张 → 平稳 → 通胀 → 放缓 → 衰退 → 危机**。

它会**同时**改变四件事：股市的长期漂移、市场波动率、**央行政策利率**（进而改变你的存贷款利率）、
以及所有店铺的客流。偶尔还会砸下世界事件——金融危机、可控核聚变商业化、地区冲突、
全球减税协议——直接改写整个盘面。

### 🏛️ 收购公司 & 世界富豪榜

每家上市公司有一个二级市场**限购比例**（苹裹只能买到 8%，小公司可以买到 100%）。
买满之后可以发起**全面收购要约**：按 20%~65% 溢价吃下剩余全部股份，取得 100% 所有权。
之后它每月直接向你上缴利润（远高于分红）——如果是亏损公司，窟窿也得你自己填。

**富豪榜上的 40 位化名富豪**（伊隆·马斯特 $364B、杰夫·贝索夫、马克·扎克伯特、沃伦·巴菲仕、
赵长朋、雷君、李佳诚…）
的身家与游戏内公司股价**实时联动**。你买走某家公司多少股份，创始人的财富就缩水多少——
**买下 100%，他直接从榜上掉下去**。

### 🏦 银行

所有利率跟随**央行政策利率**浮动，而政策利率由宏观周期决定：

- **活期**：政策利率 × 0.85，按小时计息
- **定期**：3 / 6 / 12 / 24 个月，提前支取只拿 30% 折算利息
- **信用贷**：利率 = 政策利率 + 2.2% + 信用分溢价（最高 +16%）
- **房贷**：利率 = 政策利率 + 0.4% + 信用分溢价，首付 20%~100%，5/10/20/30 年
- **信用分**（300~850）：按时还款 +2，逾期 -35 并加收 2% 罚息，负债率过高持续扣分
- **透支**：现金可以为负，按政策利率 + 19% 收罚息

- **10 个地区**各有独立的**房价指数**实时涨跌：本市 / 省会 / 一线 / 纽约 / 伦敦 / 东京 /

- **21 辆车**：$900 二手电动车 → $540 万柯尼赛格。**买任意一辆车就能解锁开车类工作**
- **游艇 / 私人飞机**：会折旧，但提供**声望**加成——声望直接提升你**所有店铺**的营收（最高 +60%）
- **腕表 / 艺术品**：跟随各自的收藏品指数波动，长期升值

## ❓ 常见问题

**Q：`Error: Cannot find module 'node:sqlite'`**
A：Node 版本太低。升级到 v24 LTS，或用 `node --experimental-sqlite server.js`。

**Q：端口被占用（`EADDRINUSE`）**
A：换端口 `PORT=9000 node server.js`；或关掉占用进程
（Windows：`netstat -ano | findstr 8020` 然后 `taskkill /PID <pid> /F`）。

**Q：桌面图标点了没反应**
A：启动日志在 `~/Library/Logs/BusinessEmpire.log`（Windows 在
`%LOCALAPPDATA%\BusinessEmpire\server.log`）。先看日志；也可以在项目目录手动
`node server.js` 看报错。

**Q：macOS 弹出"想要访问桌面文件夹"的权限询问**
A：点**允许**。存档要写在项目目录里，而桌面是受系统 TCC 保护的目录。
如果误点了拒绝，可以到「系统设置 → 隐私与安全性 → 文件与文件夹」重新打开；
或者把整个项目文件夹移到 `~/business-empire`，启动器会自动找到新位置。

**Q：数据会上传到网上吗**
A：不会。整个游戏跑在你自己的电脑上，没有任何外部请求。
